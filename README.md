# Reader Builds

This repository hosts AltStore Classic development releases for Reader.
Reader's application source remains in a separate private repository.

Add this source from AltStore Classic's **Sources** tab:

```text
https://raw.githubusercontent.com/Capelthwaite/reader-altstore/main/source.json
```

These unsigned IPA files are intended for installation through AltStore
Classic. AltStore applies the user's Apple signing identity during install.
